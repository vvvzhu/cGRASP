# Authors and contributors

## Upstream project

- **Brian E Carpenter** — author and maintainer of
  [graspy](https://github.com/becarpenter/graspy), the GRASP reference
  implementation from which this repository is derived.

## cGRASP fork

- **The cGRASP contributors** — cGRASP-over-CoAP prototype, relay,
  multicast/unicast transport, tests and documentation.

## Protocol specification

The cGRASP protocol is specified in
`draft-ietf-anima-constrained-grasp`, whose authors are:

- L. Zhu (BUPT)
- S. Jiang (BUPT)
- C. Sheng (Huawei Technologies)

Protocol authorship does not imply authorship of this code base.
